# Sorting Algorithms

# Sorting Algorithms in Java

This project demonstrates the implementation of popular sorting algorithms in Java.
Each algorithm is implemented in both:

* Ascending Order
* Descending Order

The project helps in understanding sorting logic, time complexity, and algorithm efficiency.

# Time Complexities

| Algorithm      | Best Case  | Average Case | Worst Case |
| -------------- | ---------- | ------------ | ---------- |
| Bubble Sort    | O(n)       | O(n²)        | O(n²)      |
| Selection Sort | O(n²)      | O(n²)        | O(n²)      |
| Insertion Sort | O(n)       | O(n²)        | O(n²)      |
| Merge Sort     | O(n log n) | O(n log n)   | O(n log n) |
| Quick Sort     | O(n log n) | O(n log n)   | O(n²)      |
